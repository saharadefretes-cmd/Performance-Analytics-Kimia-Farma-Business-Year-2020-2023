# Performance-Analytics-Kimia-Farma-Business-Year-2020-2023
Pada project ini dilakukan evaluasi kinerja bisnis Kimia Farma dari tahun 2020 hingga 2023. Dataset yang digunakan berisi informasi mengenai data Transaksi di Kimia Farma yang di impor melalui data yang berisi Final Transaction, Produk, Inventory dan Kantor Cabang Kimia Farma yang berisi 672 ribu baris dengan 16 kolom.
